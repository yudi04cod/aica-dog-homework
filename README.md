# Aica Dog Homework

One line, in the dog's own voice, of the excuse a dog gives after being
caught eating the homework:

> It said 'hand it in', and my mouth is my hand, so I turned it in early —
> into my stomach, where no teacher can ever mark it wrong.

`main.ts` (Node 22, standard library only, deterministic) writes that line
to `/output/entry.txt`.
